# 🎮 Games Management CRUD App (.NET Core)

A .NET application that performs **CRUD (Create, Read, Update, Delete)** operations for managing a list of games. Built with **ASP.NET Core** and **Entity Framework Core**, this project demonstrates how to create clean, maintainable backend services using modern .NET development practices.

---

## 🚀 Features

- 📝 Add new games
- 📋 View list of games
- ✏️ Edit game details
- ❌ Delete games
- 🗃 Connected to a relational database using Entity Framework
- 🌐 Clean and responsive UI with Razor Pages or MVC

---

## 🧰 Tech Stack

- ASP.NET Core (.NET 6 or 7)
- Entity Framework Core
- SQL Server (or LocalDB)
- Razor Pages or ASP.NET Core MVC
- Bootstrap (for UI styling)

---

## 📁 Project Structure

- `Models/` – Game model class
- `Controllers/` – Logic for handling requests (if using MVC)
- `Views/` – Razor views for each page (Create, Edit, Details, Delete, Index)
- `Data/` – ApplicationDbContext and database configuration
